# Chrome-dino-conntrol
Chrome Dino Hand Gesture Control

A computer vision project that allows users to control the Chrome Dino game using real-time hand gestures. Built using Python, OpenCV, and MediaPipe for accurate hand tracking and gesture detection.

Features
Real-time hand tracking using MediaPipe
Control Chrome Dino without keyboard interaction
Gesture-based jump detection
Fast and lightweight processing
Uses webcam for live input
Beginner-friendly computer vision project
Tech Stack
Python
OpenCV
MediaPipe
PyAutoGUI
How It Works

The webcam captures live video input and detects hand landmarks using MediaPipe.
Specific finger movements or gestures are recognized and converted into keyboard actions to control the Chrome Dino game.

Example:

Raise finger → Dino jumps
Hand down → No action
